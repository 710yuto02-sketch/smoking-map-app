# SMOKE SPOT - 喫煙所マップアプリ 🚬🗺️

完全ユーザー投稿型（UGC）の喫煙所探索・共有スマートフォン向けWebアプリです。
Googleマップ公式と同じ見慣れた地図画面で、紙タバコ・加熱式・屋内・屋外・料金のリアルタイム絞り込みや現在地からの徒歩ナビゲーションを提供します。

---

## ✨ 主な機能

1. **ユーザー認証**
   - ログイン・新規登録・ワンタップでお試しできるゲストログイン
2. **完全Googleマップ標準マップ**
   - 道路、コンビニ、カフェ、駅名などのおなじみの店舗・駅名ランドマークをすべて表示
   - 右上の「地図 / 航空写真」ワンタップ切り替え
   - 右下の「＋ / －」ズーム操作ボタン
3. **リアルタイム・チップ型フィルター**
   - 「紙タバコ可 / 加熱式専用」「屋内 / 屋外」「無料 / 有料」を複数選択可能
4. **徒歩ルート案内 & Googleマップ公式アプリ直接連携**
   - アプリ内での徒歩ルート・所要時間・距離の描画
   - スマートフォンの「Googleマップ公式アプリ」を直接起動して音声ナビを開始するボタン
5. **ワンタップ新規投稿**
   - ボタンをポンと選ぶだけで「紙/加熱」「屋内/屋外」「無料/有料」をサクッと登録
   - カメラ撮影・写真添付に対応
6. **口コミレビュー & 星評価**
   - 星1〜5の評価、コメント、現場写真の投稿

---

## 🛠️ 技術スタック

- **フロントエンド**: React 19, TypeScript, Vite
- **UI & アイコン**: Vanilla CSS (Mobile First), Lucide React
- **マップ**: Google Maps JavaScript API (最新 @googlemaps/js-api-loader) / フォールバック実世界マップ
- **バックエンド / DB**: Supabase (PostgreSQL + RLSセキュリティ) / Firebase Firestore対応

---

## 🚀 開発環境の起動方法

```bash
# 1. 依存ライブラリのインストール
npm install

# 2. 開発サーバーの起動（ブラウザで http://localhost:5173 を開く）
npm run dev

# 3. 本番ビルド
npm run build
```

### 環境変数の設定（任意）
`.env.example` をコピーして `.env` を作成し、Google Maps APIキーやSupabaseのキーを設定することで本番クラウドと連携します。
（※未設定でもローカルストレージにより全機能がそのままお試し可能です）
